# SkillHer — UI/UX Design Internship

SkillHer is a UI/UX design project created as part of my Skill Set Go EduTech internship. The project focuses on designing a simple, clear, and accessible learning platform for users who want to explore and develop digital skills.

## Week 1 — Design Fundamentals

### Problem Statement

Learners need a simple and visually clear way to discover relevant digital skills, choose courses, start learning, and track their progress.

### Target Users

The project focuses on learners who want to explore digital skills and access learning content through an easy-to-use interface.

### UX Work Completed

- UX principles and visual foundations
- User personas
- User flow
- Low-fidelity wireframes
- High-fidelity UI design

### User Flow

Open App → Onboarding → Home → Explore Skills → Select Course → Course Details → Start Learning → Track Progress

### Core Screens

1. Onboarding
2. Home
3. Explore Skills
4. Course Details
5. Learning Progress

### Design Focus

The design focuses on:

- Clarity
- Consistency
- Visibility
- Feedback
- Accessibility
- User Control

### Tools Used

- Figma
- GitHub
